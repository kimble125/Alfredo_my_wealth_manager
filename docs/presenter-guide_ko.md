## 3. 인사이트를 내 말로 (숫자는 이것만 기억)

1. **추세 0.97 · 계절 0.03:** 비트코인은 '언제'보다 '어느 국면인가'가 중요하다.
2. **200일선 위 +4.25% vs 아래 +1.55%(30일 뒤 중앙값):** 추세가 이어지는 성질. 단, 창이 겹치고 강세장 비중이 커서 신호로 쓰지 않는다.
3. **반감기 뒤 525·546·534일에 꼭지:** 시점은 비슷했지만 상승폭은 2,888% → 688% → 92%로 줄었다. 표본 3개라 가설이다.
4. **변동성 84%(2017) → 41%(2025), 지금 23.5%:** 시장이 성숙해졌다는 가설. 지금은 역사적으로 잔잔한 편이다(대시보드에서 하위 3%).
5. **극단적 탐욕 뒤 +5.34%:** 역발상 통념과 반대다. 강세장 속 모멘텀으로 보이지만 64구간뿐이다.
6. **예측은 '그대로'가 기준선:** 평균 오차 6.63%. 새 모델은 이걸 여러 구간에서 이겨야 쓸 만하다.

## 4. 예상 질문과 답

1. **왜 비트코인인가요?** 팀 프로젝트 Top 3 Crypto에서 코인 신호를 다뤘고, 개인 프로젝트 알프레도의 코인 탭이 '국면 설명'을 하려면 긴 흐름을 먼저 알아야 해서입니다.
2. **데이터는 어디서, 몇 개인가요?** 코인베이스 공개 API 일봉 BTC 4,112개(2015-07-20 – 2026-10-21)이고, 공포탐욕은 alternative.me 3,181일입니다. `data/collect.py`로 누구나 다시 받을 수 있습니다.
3. **결측치는 어떻게 했나요?** 날짜를 하루 간격으로 다시 세워 빈 날을 찾았습니다. 3일 이하만 채우고, XRP 904일 공백은 코인베이스가 거래를 멈춘 기간이라 비워 뒀습니다. 없는 가격을 만들지 않으려고요.
4. **이상치를 왜 안 지웠나요?** 값 오류는 0건이었고, 22일은 실제 급등락(2020-03-12 −38.8% 등)이라 위험을 재는 데 필요합니다.
5. **관찰과 해석의 차이를 예로?** 관찰은 "극단적 탐욕 뒤 30일 중앙값이 +5.34%"입니다. 해석은 "강세장 모멘텀 때문일 것"이라는 가설이고, 독립 구간 수 64개라는 한계를 같이 적었습니다.
6. **계절성이 있나요?** 확인되지 않았습니다. 요일 F = 1.36으로 5% 기준(약 2.10)보다 작고, 월별은 해마다 10–11개뿐이라 규칙으로 보기 어렵습니다. 10월이 11번 중 9번 올랐지만 다중 비교 문제가 있습니다.
7. **200일선 위가 좋다면 매수 신호 아닌가요?** 아닙니다. 30일 창이 겹쳐 표본이 독립이 아니고, 수수료도 뺐고, 2021-11처럼 200일선 위에서 하락이 시작된 때도 있습니다. 그래서 대시보드에서는 '국면 배지'로만 씁니다.
8. **예측에서 왜 '그대로'가 이겼나요?** 가격이 무작위 걷기에 가까우면 어제 값이 가장 좋은 추정이 되기 쉽습니다. 이 결과가 '예측보다 설명'이라는 설계의 근거입니다.
9. **AI를 어디에 썼고 어떻게 검증했나요?** 코드와 초안 작성에 썼습니다(REPORT 9절). 검증 방법은 이렇습니다.
   - 수집본을 같은 출처의 별도 DB와 전수 대조해 100% 일치를 확인
   - 그림을 직접 보고 축·범례 오류를 고침
   - 반감기 꼭지 정의가 2020 주기를 2024년으로 잡는 문제를 발견해 고침
   - 예측을 24구간으로 다시 잼
10. **Top 3 Crypto와 뭐가 다른가요?** Top 3는 팀이 만든 4시간봉 신호 보드입니다. 이 저장소는 제 개인 프로젝트이고, 팀 코드·디자인·매매 조건은 쓰지 않았습니다. 데이터도 공개 API에서 따로 받았습니다.
11. **대시보드는 어떻게 만들었고, 왜 Streamlit이 아닌가요?** 파이썬이 데이터를 HTML 한 파일에 넣고, 화면은 순수 자바스크립트로 그립니다. 평가자가 설치 없이 열 수 있게 하려고 이렇게 했습니다.
12. **한계는요?** 한 거래소 가격만 썼고, 외부 변수(금리·ETF 자금)가 없고, 겹치는 창과 다중 비교 문제가 있습니다. 반감기 표본도 3개뿐입니다(REPORT 8절).
