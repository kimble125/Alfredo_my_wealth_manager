# 알프레도 · 기술 (지금 설명할 수 있는 것, v0)

| 기술 | 사용자가 보는 문장 예 | 숫자의 출처(코드) |
|---|---|---|
| 기간 요약 | "최근 1년 $107,586 → $84,025, 수익률은 −21.9%예요" | 대시보드 `stats()` · 기간 첫·끝 종가 |
| 최대 낙폭 설명 | "가장 크게 떨어진 폭은 −48.9%(2025-10-26 → 2026-06-30)였어요" | `stats()` · 누적 최고가 대비 |
| 추세 국면 | "종가가 200일 이동평균 위에 있어요" + (자세히) 국면별 30일 뒤 중앙값 | `series().ma[200]`, `outputs/summary.json` trend |
| 변동성 위치 | "30일 변동성 23.5%, 전체 기록 중 하위 3%예요" | `series().vol`, 전체 기록 백분위 |
| 시장 심리 | "공포탐욕 지수는 63(탐욕)이에요" + (자세히) 분류별 30일 뒤 결과 | alternative.me 자료, `summary.json` fear_greed_forward |
| 예측에 대한 태도 | "앞날 숫자는 드리지 않아요. 단순한 기준선도 이기기 어려웠어요" | `summary.json` forecast.rolling_origin |
| 용어 풀이 | 최대 낙폭·200일 이동평균·변동성·공포탐욕 지수를 한 문장으로 | `bubbles()`의 '쉽게' 문장 |

- 숫자는 모두 화면 자료나 `outputs/summary.json`에서만 가져옵니다(규칙 기반, AI 호출 없음).
