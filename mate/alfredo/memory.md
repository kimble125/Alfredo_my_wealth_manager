# 알프레도 · 기억 (v0, 아직 기억 기능 없음)

| 기억해도 되는 것(다음 단계 후보) | 기억하지 않는 것 |
|---|---|
| 사용자가 고른 화면 설정(코인·기간·쉽게/자세히) | 계좌·금액·보유 종목·연락처 등 개인 재무 정보 |
| 사용자가 저장하라고 한 분석 메모(예: "2022 약세장과 비교해 보기") | 대화 원문 전체 |
| 자주 묻는 용어 | 다른 사람에 대한 정보 |

- 지금은 아무것도 저장하지 않습니다(대시보드는 파일 하나, 채팅 서버는 대화를 저장하지 않음).
- 기억을 붙일 때는 사용자 동의 화면과 지우기 기능을 먼저 만듭니다.
