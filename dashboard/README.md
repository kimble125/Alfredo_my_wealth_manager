# 보너스 1 · 알프레도 코인 분석 대시보드

분석 결과를 **기간·조건을 바꿔 보며** 탐색하는 웹 대시보드입니다. 제출 형식은 미션 보너스의 **(3) 대시보드 스크린샷 세트 + 필터/기간 변경 시나리오 설명** 입니다.

- **열기:** `dashboard/index.html`을 브라우저로 열면 됩니다(더블클릭). 데이터가 파일 안에 들어 있어 **서버·인터넷·설치가 필요 없고**, 바깥 주소를 부르지 않습니다.
- **다시 만들기(데이터를 새로 받았을 때):** `python dashboard/build_dashboard.py`(먼저 `python analysis.py`). `template.html`에 데이터를 넣어 `index.html`을 만듭니다.
- **바로 가는 주소:** `index.html#코인/기간`. 예를 들어 `#ETH/1095`는 이더리움 3년, `#BTC/bear22`는 비트코인 2022 약세장입니다.

## 화면 구성 (알프레도 공통 화면 규칙: 상황판 약 3/4 + 메이트 칸 약 1/4)

| 영역 | 내용 |
|---|---|
| 조건 줄 | 코인(BTC·ETH·XRP) · 기간(1개월·3개월·6개월·1년·3년·전체) · 장면(2017 거품, 2020–21 강세장, 2022 약세장, 4차 반감기 뒤) · 이동평균(20·50·200일 켜고 끄기) · 변동성 창(14·30·90일) · 로그 축 |
| 숫자 카드 5개 | 기간 수익률, 최대 낙폭(고점→저점 날짜), 변동성(연율, 전체 기록 중 위치), 추세 국면(기간 끝 종가가 200일선 위/아래, 기간 중 위였던 날 비율), 공포탐욕(기간 끝) |
| 그래프 3개 | 가격 + 이동평균(마우스를 올리면 날짜별 값, 20일선 노랑·50일선 파랑·200일선 빨강), 변동성, 공포탐욕(극단 구간 색칠) |
| 알프레도 칸 | 고른 조건의 숫자로 문장을 만드는 **규칙 기반 해설**. '쉽게'는 용어 풀이, '자세히'는 리포트의 참고 통계(200일선 국면별 30일 뒤 수익률, 공포탐욕 분류별 결과, 예측 기준선 결과)를 덧붙입니다. AI를 부르지 않으므로 같은 조건이면 늘 같은 문장이 나옵니다. 사고팔 시점·비중은 말하지 않습니다 |

  - 변동성 = 일간 로그수익률 표준편차 × √365. 빈 날이 섞인 창은 계산하지 않습니다(이동평균도 같음)

## 계산할 때 리포트와 다른 점 (알아 둘 것)

1. **빈 날 처리:** 리포트(`analysis.py`)는 3일 이하 공백을 직전 값으로 채웠다. 대시보드는 모든 빈 날을 비워 두고, 빈 날이 섞인 창은 이동평균·변동성을 계산하지 않는다. 그래서 ETH 2016-05-21–22 근처 값이 조금 다를 수 있다.
2. **200일선 위 비율의 분모:** 기간 안에서 200일선을 계산할 수 있는 날만 센다.
3. **변동성 위치(하위 %):** 지금 가진 전체 자료와 비교한 사후 값이다. 과거 장면을 볼 때 그 시점에 알 수 있던 숫자가 아니다.
4. **'자세히'의 참고 통계는 모두 BTC 기준이다.** ETH·XRP를 고르면 "선택 코인이 아니라 BTC 기준"이라고 함께 표시한다.
5. **공포탐욕 지수는 비트코인 중심 지수다**(alternative.me, 구성에 비트코인 변동성·모멘텀 포함).
